# 边坡监测周报自动化模板梳理

参考文件：`第47期-2025.12.8~2025.12.14边坡监测周报-长江水利委员会长江科学院(1)(1).docx`

## 一、报告结构

这类周报建议在系统中作为“周报模板”维护，模板本身保留固定行文、标题层级、表格标题和图名，具体数据由系统按报告期、标段、边坡和监测类型自动填充。

### 封面

- 项目名称：房县至五峰高速公路兴山至长阳段
- 合同段：SYXCBP-1合同段
- 报告名称：边坡监测工作周报
- 期号：第 `{期号}` 期
- 编制、审核、签发人
- 编制单位
- 报告日期：`{报告日期}`

### 1 本周工作完成情况

建议拆为四个子模块：

- 边坡监测情况概述
- 设计符合性核查情况
- 边坡监测与预警情况
- 本周天气情况

可用占位符：

- `{报告标题}`
- `{报告类型}`
- `{报告日期}`
- `{标段}`
- `{边坡名称}`
- `{本期监测完成率}`
- `{边坡监测台账表}`
- `{边坡空间位置表}`
- `{雨量位移叠加图}`

### 1.2 分边坡监测详情

这是自动生成的核心区域。系统应按“标段 > 边坡 > 监测类型”循环生成小节。每个边坡小节建议包含：

1. 边坡概况与施工状态
2. 本周监测频次、测点数量、有效观测日期
3. 地表水平位移/沉降成果表
4. 地表位移趋势图
5. 变化速率图，参考值暂按 `±2mm/d`
6. 深部水平位移测斜曲线，如该边坡存在测斜孔
7. 雨量与位移叠加图，如报告期存在雨量数据
8. 监测结论与后续建议

可用占位符：

- `{地表位移统计表}`
- `{地表位移趋势图}`
- `{变化速率图}`
- `{深部测斜曲线}`
- `{平均监测频率统计}`
- `{雨量位移叠加图}`
- `{监测布点图}`
- `{监测结论}`

### 1.3 现场施工巡查情况

建议按标段自动汇总巡检记录，重点输出“有问题/需整改”的记录。无异常时输出标准结论，有异常时输出问题表和照片。

可用占位符：

- `{巡检问题汇总}`
- `{预警处置记录}`

### 1.4 其他工作完成情况

建议作为人工补充模块，支持填写：

- 新增测点
- 加密监测
- 设计复核
- 资料整理
- 现场协调

### 2 下周重点工作安排

建议系统根据以下数据辅助生成初稿：

- 未更新测点
- 临近巡检计划
- 未关闭整改问题
- 活跃预警
- 施工扰动较大的边坡

### 3 急待解决问题及合理化建议

建议保留为“系统初稿 + 人工确认”模块，系统可以基于巡检问题、预警记录、降雨、异常变化速率自动列出建议。

## 三、系统修改建议

### 第一优先级：模板可用性

- 模板上传后，系统应展示每个占位符是否已绑定到真实数据源。
- 对 Word/PDF 模板解析出的占位符，提供“一键按标准字典绑定”。
- 未绑定占位符在生成报告前应给出拦截提示。
- 对 50MB 左右的大模板，解析过程应有明确进度和失败原因。

### 第二优先级：分边坡循环生成

当前系统已有结构化报告材料接口，但这份周报需要“按边坡重复生成小节”。建议新增：

- `{分边坡监测详情}` 复合占位符。
- 按标段、边坡名称、桩号顺序生成 `1.2.x` 小节。
- 自动判断监测类型：地表位移、沉降、深部测斜、裂缝、锚索应力。
- 某边坡缺少某类数据时，不输出空图空表，只输出“本期未布设/未采集”。

### 第三优先级：报告文字自动生成

建议把常见结论做成规则模板：

- 变化速率未超过 `±2mm/d`：输出“变形速率处于可控范围内”。
- 存在超过参考值的测点：列出测点、日期、最大速率、建议复核。
- 深部测斜无明显拐点：输出“未发现潜在滑移带迹象”。
- 有巡检问题：自动插入整改责任人、期限、当前状态。
- 有降雨：自动生成“降雨-变形响应”描述。

### 第四优先级：导出质量

- 图表统一论文风格：白底、细网格、清晰图例、单位完整、参考线明确。
- Word 导出图片建议使用 300dpi 以上。
- 表格建议固定列宽，日期列横排，测点编号不换行。
- 图片和图表题名按“图1.2.x-x”“表1.2.x-x”自动编号。

## 四、建议的数据闭环

为了稳定生成这类报告，系统中至少需要保证以下数据完整：

- 边坡台账：标段、边坡名称、桩号、类型、施工状态、风险等级。
- 测点台账：测点编号、监测类型、初始日期、是否损坏、是否恢复。
- 监测数据：日期、测值、单位、采集批次、是否有效。
- 深部测斜：孔号、埋深、基准日期、测读日期、深度、累计位移。
- 巡检记录：巡查日期、巡查方式、问题部位、问题等级、整改状态、照片。
- 天气雨量：日期、最高/最低温、天气、日雨量、数据来源。
- 地图布点：边坡空间位置、布点图、图层来源。
