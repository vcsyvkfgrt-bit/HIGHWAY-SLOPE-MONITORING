# 报告智能初稿与质量检查

## 启用智能初稿

智能初稿是可选功能。未配置时，系统继续使用原有规则模板生成报告。

在后端 `.env` 中配置：

```env
OPENAI_API_KEY=服务端密钥
OPENAI_REPORT_MODEL=账号可用且支持结构化输出的模型名称
```

也可以切换到 OpenRouter：

```env
AI_PROVIDER=openrouter
OPENROUTER_API_KEY=新生成的服务端密钥
OPENROUTER_MODEL=inclusionai/ling-3.0-flash-vl:free
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1
```

当前 Ling 3.0 Flash VL 免费模型不支持 `response_format`。系统会改用指定函数工具返回报告结构，再在服务端校验章节完整性和数据依据；若模型没有按要求返回，将拒绝该初稿并提示重试或更换模型。

重启后端服务后，报告生成页会出现“生成智能初稿”按钮。密钥只在服务端读取，不会返回浏览器或写入报告。

系统只向模型发送当前报告范围的压缩统计素材，并要求：

- 事实、计算、分析、建议分开；
- 每个有效段落给出 `summary.*` 或 `materials.*` 数据依据；
- 没有证据时明确写“待人工补充”；
- 变化速率参考值不得表述为法定阈值或最终安全结论；
- 人工核对并确认后才能写入正文。

## 报告质量检查

报告预览页和报告列表均可运行检查。当前覆盖：

- 标题、编制人、报告日期和正文完整性；
- 模板残留字段与图表引用；
- 空表、空图、表格字段缺失和宽表版式风险；
- 图表日期、数值、单位及图题完整性；
- 已选数据与统计素材的数量口径；
- 结论和智能段落的数据来源可追溯性；
- 智能正文是否完成人工确认；
- Word/PDF 最终版式人工复核提醒。

“必须修正”项不影响保存草稿，但会阻止正式 Word 导出。“建议复核”和“提示”允许导出，由编制人确认。

## 版本管理

报告内容、智能初稿、人工确认状态和数据来源会随报告版本一起保存。报告详情中的“与当前比较”可查看历史版本与当前版本的正文模块变化。
